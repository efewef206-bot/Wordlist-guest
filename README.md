# Wordlist guest

Targeted wordlist generator (CUPP-style) for auditing **your own** passwords
or authorized pentests. Pure Python. No dependencies. No network calls.

> ⚠️ Using the output against accounts you don't own is a crime (PECA §3–4,
> CFAA, CMA). See license.

## Install

```bash
git clone https://github.com/efewef206/Wordlist guest.git
cd Wordlist guest
python Wordlist guest.py          # interactive
